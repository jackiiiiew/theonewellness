# One Wellness Workshop Static Website

This is a rebuilt static HTML/CSS version inspired by the PSD template.

Files:
- `index.html`: English version
- `zh.html`: Chinese version
- `styles.css`: shared stylesheet
- `assets/`: place images, logo, QR code, team photos here

Deployment:
1. Upload these files to a GitHub repository.
2. Enable GitHub Pages from the repository settings.
3. Use `index.html` as the homepage.

Edit suggestions:
- Replace placeholder text with final OneWellness content.
- Replace the CSS gradient hero with a real background image if available.
- Replace the donation placeholder with a QR code image.
- Replace team placeholders with real photos.
